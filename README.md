# Dahu Order Notes

Makes the WooCommerce order notes a person actually wrote stand out from the
ones WooCommerce and its extensions generate on their own.

Developed and maintained by [Hugo Vial-Jaime — Dahu-Concept](https://dahu-concept.fr).

## The problem

On a busy shop, the order notes panel fills up with machine-generated entries —
status changes, stock movements, refunds, tracking numbers, invoice events. The
one note that matters, the one a colleague typed about this particular customer,
is buried among them.

WooCommerce already styles customer notes and system notes differently. What it
cannot style is the third category: notes generated by code *while a staff
member is logged in*. Changing an order status from the admin screen produces a
note attributed to that person, indistinguishable in the markup from a note they
typed themselves.

Dahu Order Notes identifies those, and leaves the hand-written ones highlighted.

## How detection works

Automatic notes can only be recognised by their wording. Hardcoding that wording
would tie the plugin to one language, so instead it rebuilds its patterns at
runtime from WooCommerce's own translatable strings:

```php
__( 'Order status changed from %1$s to %2$s.', 'woocommerce' )
```

Placeholders become wildcards, the rest is matched literally. A French shop
therefore matches `État de la commande modifié de …`, a German one
`Bestellstatus geändert von …`, with no configuration and no translation file of
its own.

Note content is normalised before matching — HTML stripped, entities decoded,
every kind of whitespace flattened — because WooCommerce notes routinely carry
non-breaking spaces, which French typography puts before every colon.

## Features

- Highlights hand-written private notes on the order screen
- Locale-independent detection, rebuilt from WooCommerce's own translations
- Configurable highlight colours
- Additional phrases configurable from the settings screen, no code required
- `dahu_order_notes_auto_patterns` filter for developers
- Works with both legacy order storage and High-Performance Order Storage
- Never writes to the database; deactivating leaves no trace

## Installation

1. Download the latest release, or clone this repository into
   `wp-content/plugins/`.
2. Activate the plugin through the Plugins screen.
3. Optionally adjust the colours under **WooCommerce → Dahu Order Notes**.

Highlighting is on by default.

## Configuration

| Setting | Effect |
|---|---|
| Highlighting | Turns the highlight on or off. |
| Hand-written note colour | Background of notes identified as hand-written. |
| Customer note header colour | Background of the header on notes sent to the customer. |
| Additional automatic notes | One phrase per line. Any note starting with one of them is treated as automatic. Plain text, not regular expressions. |

## For developers

Add your own patterns, as complete PCRE expressions:

```php
add_filter( 'dahu_order_notes_auto_patterns', function ( array $patterns ) {
    $patterns[] = '/^Tracking number added/i';
    return $patterns;
} );
```

Change the admin screens the highlight applies to:

```php
add_filter( 'dahu_order_notes_order_screens', function ( array $screens ) {
    $screens[] = 'my_custom_order_screen';
    return $screens;
} );
```
