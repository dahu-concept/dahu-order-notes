Makes the order notes a person actually wrote stand out from the ones WooCommerce generates on its own.

== Description ==

On a busy shop, the order notes panel fills up with machine-generated entries:
status changes, stock movements, refunds, tracking numbers, invoice events. The
one note that matters — the one a colleague typed about this particular
customer — is buried among them.

WooCommerce already styles customer notes and system notes differently. It
cannot style the third category: notes generated by code *while a staff member
is logged in*. Changing an order status from the admin screen produces a note
attributed to that person, indistinguishable in the markup from a note they
typed themselves.

Dahu Order Notes identifies those and leaves the hand-written ones highlighted.

= How detection works =

Automatic notes are recognised by their wording. Rather than hardcoding that
wording in one language, the plugin rebuilds its patterns at runtime from
WooCommerce's own translatable strings. It therefore follows whatever locale
your shop runs in, with no configuration — French, German, Spanish or any other
translated locale works out of the box.

Notes added by other plugins can be declared in the settings screen, one phrase
per line, or through a filter for developers.

= What it does not do =

The plugin never writes to the database and never alters a note's content or
metadata. Everything is computed at display time. Deactivating it leaves no
trace.

= Features =

* Highlights hand-written private notes on the order screen
* Locale-independent detection, rebuilt from WooCommerce's own translations
* Configurable highlight colours
* Additional phrases configurable from the settings screen, no code needed
* `dahu_order_notes_auto_patterns` filter for developers
* Works with both legacy order storage and High-Performance Order Storage

= External services =

This plugin does not contact any external service.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`, or install it from the
   Plugins screen.
2. Activate it through the Plugins screen.
3. Go to WooCommerce > Dahu Order Notes to adjust the colours if you want to.

Highlighting is on by default; there is nothing to configure to get started.

== Frequently Asked Questions ==

= Does it work on a shop that is not in English? =

Yes, and that is the point. The detection patterns come from WooCommerce's own
translated strings, so the plugin adapts to the shop's locale on its own.

= A plugin of mine adds notes that are not detected =

Add the beginning of the note's text in WooCommerce > Dahu Order Notes, one phrase
per line. Developers can use the `dahu_order_notes_auto_patterns` filter instead.

= Does it modify my order notes? =

No. Nothing is written to the database at any point.

= Is it compatible with High-Performance Order Storage (HPOS)? =

Yes.
